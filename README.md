i made this since windows' built in brightness slider only works for laptops and other all-in-one pcs. this app utilises the computers' ability to communicate with the monitor and allow the sending of commands to-and-fro via DDC\CI , to create a convenient brightness slider to be used at any time, while using a miniscule amount of ram.

All you need to do is run the let-there-be-light.exe (or runrun.exe, dont ask why theres two of them, you only need one) file(s). **Please set it to be a startup app**, so you have on-demand brightness controls at all times. :))
